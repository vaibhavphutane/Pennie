# Evidence availability

The repository includes the synthetic inference test results, replacement-range checks, Keychain fixture results, and metadata-only application diagnostics from the local validation run. These are historical results, not claims of live integration coverage. See [the validation matrix](../VALIDATION.md) for pending checks and reproducible commands.

Raw REA response envelopes, decompiler output, binary excerpts, machine-specific runtime inventories, screenshots, and build manifests remain in the original local workspace and are excluded from Git. References to those artifacts in the reports identify the local investigation record; they are not downloadable files in this repository. No Grammarly executables or assets are distributed here.

The [reverse-engineering report](../REVERSE_ENGINEERING.md) retains source identities, evidence IDs, findings, limitations, and their connection to implementation choices. The public application uses its own source code and prompts.

## What cannot be recovered from these artifacts

This inspection does not recover Grammarly's hosted models, server prompts, training data, ranking systems, entitlement logic, online experiment configuration, or cloud service implementation. Static symbols cannot establish that every grammar operation requires a network call or that no local linguistic models exist. Current capture, formatting, focus, and cursor behavior in Outlook, Teams, and Slack must be checked in those applications at runtime.

No proprietary executable, font, icon, JavaScript bundle, or algorithm was copied into the independent application. Saved excerpts serve only as bounded analysis evidence.
